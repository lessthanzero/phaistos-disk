# Phaistos Disc Lab: Autonomous Distributed Compute & Model Protocol

## Mandate
Per laboratory guidelines (`AGENTS.md`), all intensive computational workflows—including statistical surrogate generation, Monte Carlo null hypothesis testing, MCMC parameter fitting, physical acoustic rendering, and test verification—must be automatically distributed across all available compute nodes and model backends without requiring repeated user prompts.

## Autonomous Workflow Execution

1. **Pre-Flight Push**:
   ```bash
   ./scripts/sync_artifacts.sh pc push
   ```
2. **Remote Batch / Test Run**:
   ```bash
   ./scripts/remote_worker.sh pc "cd ~/Developer/phaistos-disk && uv run <command>"
   ```
3. **Artifact Retrieval**:
   ```bash
   ./scripts/sync_artifacts.sh pc pull
   ```
4. **Bimodal Cross-Platform Verification**:
   - macOS: `uv run pytest`
   - Linux: `./scripts/remote_worker.sh pc "cd ~/Developer/phaistos-disk && uv run pytest"`
